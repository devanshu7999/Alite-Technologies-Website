# Alite Technologies — Frontend Website

A responsive single-page marketing website inspired by the supplied Alite Technologies reference image.

## Included
- `index.html` — complete page structure
- `styles.css` — responsive design, animations and blue/white visual system
- `script.js` — mobile navigation and scroll-reveal effects

## Run
Open `index.html` directly in a browser, or serve the folder with any static server.

## Customize
- Change contact details in `index.html`.
- Replace the placeholder A brand mark with your final logo if desired.
- Edit colors at the top of `styles.css` using `--blue`, `--blue-dark`, etc.
